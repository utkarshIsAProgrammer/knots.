- **Implemented X3DH + Double Ratchet** cryptography protocol providing forward secrecy and post-compromise security across 500+ lines of client-side TypeScript
- **Designed server-blind architecture** minimizing PII; server stores only hashed Knot IDs, public keys, and encrypted blobs — even database breach reveals no user data
- **Optimized for free-tier sustainability**: All services (Render, Vercel, Ably, Supabase, MongoDB Atlas M0, Cloudflare R2) operate without credit card requirements

- **Implemented offline message delivery** via MongoDB TTL indexes, ensuring messages reach offline recipients without persistent WebSocket connections
